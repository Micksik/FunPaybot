# ⚡ FunPay Sales Bot (PySide6 Edition)

Автоматизированный десктопный менеджер для продавцов на FunPay. Приложение позволяет полностью автоматизировать рутинные задачи: от ответов покупателям до выдачи одноразовых и многоразовых цифровых товаров из встроенной базы данных.

## ✨ Основные возможности

* ** Авторизация по Golden Key:** Подключение к FunPay без использования веб-эмуляторов (Selenium/Playwright) — работа напрямую через HTTP-сессии.
* ** Автоответчик:** Автоматическая отправка приветственных сообщений при появлении новых діалогов.
* ** Автовыдача товаров:** 
  * Распознавание ключевых слов в сообщениях покупателя.
  * Выдача одноразовых ключей/аккаунтов с автоматическим списанием из базы SQLite.
  * Выдача многоразового текста (ссылок, инструкций).
  * Поддержка импорта/экспорта базы товаров в JSON.
* ** Учет и статистика:** Фиксация всех продаж, подсчет общей выручки и возможность экспорта историй продаж в CSV.
* ** Telegram-уведомления:** Мгновенные алерты в твой TG-чат при автовыдаче товара или запуске бота.
* ** Поддержка прокси:** Возможность работы через HTTP/HTTPS прокси-серверы.
* ** Современный UI:** Кастомный графический интерфейс на PySide6 с динамическим фоном и анимированными элементами.
